# ENERGYVERSE: The Journey of Energy

A futuristic educational website that explores how energy transforms from one form to another in the real world.

## Features included
- Interactive energy conversion simulator for ten systems
- Animated energy flow diagram
- 3D-inspired laboratory with clickable devices
- Live experiment controls for solar intensity, wind speed, water flow, and motor power
- Energy conservation demonstration with useful output vs surroundings
- AI science assistant chat panel
- Quiz and challenge mode with instant feedback

## Run locally
Open `index.html` directly in a browser, or serve the folder with a simple local web server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Project structure
- `index.html` — page layout
- `styles.css` — futuristic neon design and responsive styling
- `app.js` — device data, interactive logic, simulation controls, quiz, and assistant behavior

## Design goal
This project is designed for a school science exhibition and emphasizes clarity, interactivity, and strong visual feedback while teaching the core principle that energy is transformed rather than created or destroyed.
